Este é projeto desenvolvido com o intuito de aprimorar habilidades de front e banck-end. Trata-se de um gerenciador de tarefas com sistema de prioridades, categorias, drag-and-drop, relatórios estatisticos e modo claro e escuro. 
As tecnologias utulizadas para o front-end foram: 
HTML
CSS
JAVASCRIPT
REACT.JS
BOOTSTRATP
Para o back-end foram usadas:
NODE.JS
EXPRESS.JS
MONGODB
MONGOOSE
